# Formulário Incrível 🎓

Protótipo web institucional da equipe, desenvolvido como parte do **Desafio Prático: Construção de Site Institucional da Equipe**.

O site apresenta o projeto, suas funcionalidades, o mural da equipe e os canais de contato de cada integrante, encerrando com um formulário de avaliação interativo.
